# FPS Game - 几猫3A大作

一款基于Web的第一人称射击游戏，完全使用HTML/CSS/JavaScript实现。

## 在线游玩

🎮 **游戏地址**: https://18236324510.github.io/fps_game/

## 特性

- 完整的FPS游戏体验
- 自包含的单文件HTML实现
- 无需额外依赖或服务器
- 支持移动端和桌面端

## 本地运行

直接在浏览器中打开 `index.html` 文件即可开始游戏。

或使用本地服务器：

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

## 技术栈

- HTML5
- CSS3
- JavaScript (ES6+)
- WebGL/Canvas

## 项目结构

fps_game/
